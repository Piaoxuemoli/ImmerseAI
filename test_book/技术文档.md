# ImmerseAI 技术文档

## 项目简介

ImmerseAI 是一款 Local-First 的沉浸式阅读与角色扮演 Agent 桌面应用。它通过 MCP (Model Context Protocol) 连接本地书库，利用端侧 RAG 技术理解书籍内容。

## 核心特性

### 1. 本地优先架构

所有数据完全本地化，保护用户隐私：

- 书籍文件存储在本地文件系统
- 向量索引使用 IndexedDB 持久化
- 仅在 LLM API 调用时有网络请求

### 2. RAG 引擎

基于 Web Worker 的向量化检索系统：

```javascript
// 使用 Transformers.js 进行向量化
const embedding = await pipeline('feature-extraction', 'Xenova/all-MiniLM-L6-v2');

// Orama 作为向量数据库
const db = await create({
  schema: {
    text: 'string',
    paragraphIndex: 'number',
    embedding: 'vector[384]'
  }
});
```

### 3. 智能角色扮演

用户可以基于书籍内容创建角色，与其进行自然对话。角色的回答基于书中的真实内容，通过 RAG 检索相关段落。

## 技术栈

- **前端**: React 18 + TypeScript + TailwindCSS
- **桌面框架**: Electron 28
- **状态管理**: Zustand
- **向量化**: Transformers.js (all-MiniLM-L6-v2)
- **向量数据库**: Orama
- **LLM**: OpenAI 兼容 API

## 系统架构

```
渲染进程 (React)
    ↓
主进程 (Electron)
    ↓
MCP Server (本地文件系统)
    ↓
RAG Worker (向量化 + 检索)
    ↓
LLM API (对话生成)
```

```bash

```

### 构建应用

```bash
npm run build
npm run pack
```

## 最佳实践

1. **性能优化**: 所有计算密集型操作必须在 Web Worker 中执行
2. **类型安全**: 使用 TypeScript strict 模式，禁止使用 `any`
3. **UI 设计**: 遵循 Notion 极简风格，使用 slate 色系
4. **错误处理**: 所有异步操作必须使用 try-catch
