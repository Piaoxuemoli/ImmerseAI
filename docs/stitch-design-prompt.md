# ImmerseAI UI 重构 - Stitch 设计稿 Prompt

## 设计目标
创建一套简约但交互感强的现代阅读伴侣应用 UI，保持功能完整的同时追求视觉愉悦和流畅交互体验。

---

## 整体设计风格

**设计语言**：Neo-Brutalism 融合极简主义
- 干净的线条和几何形状
- 微妙但有存在感的阴影
- 活泼但不刺眼的色彩点缀
- 强调内容层次和可读性

**设计关键词**：简约 · 沉浸 · 温暖 · 智能 · 轻盈

## 组件设计规范

### 按钮 (Button)

**变体**：
- Primary：填充 accent-primary，白色文字
- Secondary：描边边框，accent 文字
- Ghost：透明背景，hover 时浅灰
- Danger：红色系，用于删除操作

**尺寸**：
- sm：高度 32px，内边距 12px
- md：高度 40px，内边距 16px
- lg：高度 48px，内边距 20px
- icon：40x40px 方形

**状态**：
- Default → Hover（背景加深 10%）→ Active（缩放 0.98）→ Disabled（opacity 50%）

**动画**：
- Hover：50ms 过渡
- Click：scale(0.98) + 100ms 回弹

### 输入框 (Input)

**样式**：
- 高度 44px（适合触控）
- 圆角 8px
- 边框 1px solid var(--border)
- 聚焦时边框变为 accent-primary

**状态**：
- Default → Focus（边框 accent + 微弱 glow）→ Error（红色边框）→ Disabled

### 卡片 (Card)

**样式**：
- 背景：var(--surface)
- 圆角：12px
- 阴影：0 2px 8px rgba(0,0,0,0.08)

**状态**：
- Default → Hover（translateY(-2px) + shadow 增强）

**动画**：
- Hover 过渡：200ms ease-out

### 模态框 (Dialog)

**样式**：
- 居中显示
- 背景遮罩：rgba(0,0,0,0.4)，backdrop-blur 4px
- 圆角：16px
- 最大宽度：480px

**动画**：
- 进入：fade-in + scale(0.95 → 1)，200ms
- 退出：fade-out + scale(1 → 0.95)，150ms

### Toast 通知

**位置**：顶部居中，距离顶部 80px
**样式**：圆角 8px，阴影，圆角 12px
**动画**：从顶部滑入，3 秒后自动消失

## 交互动效

### 页面切换
- 退出：fade-out 150ms
- 进入：fade-in + slide-up 200ms

### 列表项
- 进入：依次淡入，间隔 50ms
- 删除：向左滑出 + 高度收缩

### 按钮反馈
- Hover：背景色变化 + 微弱上浮
- Click：轻微缩放 + 回弹

### 加载状态
- 骨架屏（Skeleton）闪烁动画
- 按钮加载：文字替换为旋转图标

### 空状态
- 柔和插图 + 引导文案
- 淡入动画
