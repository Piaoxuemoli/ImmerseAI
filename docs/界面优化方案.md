/* globals.css — 补充 */

## 十二、总结

**核心原则**：
1. 所有硬编码颜色应改为 CSS 变量或 Tailwind 主题色
2. 所有图标按钮必须包含 aria-label
3. 所有弹层组件使用 Portal 渲染
4. 移动端优先设计，触摸目标 ≥ 44px
5. 动画时长不低于人类感知阈值（≥ 200ms）

**实施建议**：按优先级排序，高优先级问题可在下一版本迭代中全部修复，预计工作量 2-3 天。
